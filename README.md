# تلاوتي

تطبيق ويب لتدريب التلاوة والحفظ، يعمل بالكامل في المتصفح بدون خادم.

- **تعرّف تلقائي على السورة**: ابدأ التلاوة من أي موضع في المصحف (١١٤ سورة) ويتابعك كلمة بكلمة.
- **أحكام التجويد**: تلوين تحت الكلمات، وشرح الحكم عند الضغط على أي كلمة، وتنبيه للحكم القادم أثناء التلاوة.
- **وضع الحفظ**: تُخفى الكلمات وتظهر عند تلاوتها أو بالضغط عليها.
- **تقدّمك**: هدف يومي، أيام متواصلة، رسم آخر ٧ أيام، والكلمات التي تتعثر فيها.
- **PWA**: يُثبَّت على الهاتف ويعمل بعد أول تحميل بدون إنترنت (عدا التعرّف على الصوت).

## التشغيل محليًا

لا بد من خادم ويب (التطبيق يحمّل `data/quran-uthmani.txt`):

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على GitHub Pages

1. أنشئ مستودعًا وارفع كل الملفات في الفرع `main`.
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. أي `push` على `main` ينشر الموقع تلقائيًا عبر `.github/workflows/pages.yml`.

## ملاحظات

- التعرّف على الصوت يستخدم Web Speech API (`ar-SA`) ويعمل في Chrome وEdge وSafari، ويحتاج HTTPS وإذن الميكروفون. بعض المتصفحات ترسل الصوت لخوادمها للمعالجة.
- عند نشر تحديث كبير غيّر رقم `V` في `sw.js` لتحديث الكاش.
- أحكام التجويد تُستنتج من النص بقواعد مبسّطة وللتدريب فقط، وليست بديلًا عن معلّم.
